# 윷놀이 말판 (심사2국 워크숍)

실제 윷을 던지고, **진행석(내무계)** 이 결과를 누르면 **팀 대표가 패드에서 말을 옮기고**, 프로젝터에는 **3D 말판**이 1초 안에 따라 움직이는 Streamlit 앱입니다.
판은 서버 한 곳에 있어서 노트북·패드·휴대폰 어느 기기에서 바꿔도 같은 판을 봅니다. 로그인은 필요 없습니다.

## 화면 세 개 (주소 하나)

| 화면 | 주소 | 누가 / 어디서 |
|---|---|---|
| 스크린 | `https://앱주소/?view=screen` | 노트북 → 프로젝터 (F11 전체 화면, 한 번 클릭하면 효과음) |
| 진행석 | `https://앱주소/?view=ctrl` | 내무계 직원 (노트북 화면 또는 휴대폰) — 윷 결과 버튼 |
| 말 옮기기 | `https://앱주소/?view=pad` | 팀 대표 (갤럭시탭) — 번호 누르고 '움직이기' |

`https://앱주소/` 로 들어가면 세 화면으로 가는 버튼이 나옵니다.

## 진행 순서

1. 윷을 던집니다.
2. 진행석에서 결과(도·개·걸·윷·모·빽도)를 누릅니다. 스크린에 큰 글씨로 나옵니다. 윷·모면 한 번 더 던집니다.
3. 팀 대표가 패드에서 **말 번호**를 누릅니다(스크린의 말 위에도 같은 번호가 떠 있음). 스크린에 빨간 점선으로 갈 길이 보입니다.
4. 맞으면 **✔ 이 말로 움직이기**. 스크린에서 말이 칸마다 콩콩 뛰어갑니다. 잡기·업기·나기는 자동으로 처리됩니다.
5. 결과가 여러 개 모여 있으면 패드에서 어느 결과부터 쓸지 먼저 고릅니다.

규칙: 모·뒷모·방에 **멈춘** 말만 지름길 · 같은 팀 말은 업기 · 상대 말을 잡으면 한 번 더 · 빽도는 왔던 길로 한 칸(도에서 빽도면 참먹이에 섰다가 다음에 나감).
진행석 아래 [새 게임]에서 팀 수(2~4)·말 수·빽도·'참먹이를 지나야 나가기' 규칙을 바꿀 수 있습니다.

## 배포 (Streamlit Community Cloud, 무료 — 심사 시스템과 같은 방법)

1. GitHub에 새 저장소를 만들고 이 폴더의 파일을 모두 올립니다: `app.py`, `yutcore.py`, `board_engine.py`, `requirements.txt`, `static/screen.js`, `static/screen.css`, `.streamlit/config.toml`
   - `.streamlit`, `static` 폴더는 GitHub 웹에서 "Create new file"로 `static/screen.js`처럼 경로째 이름을 넣어 만들면 됩니다.
2. share.streamlit.io → Create app → 저장소 선택, Main file `app.py`, Python 3.12 → Deploy. (Secrets는 필요 없습니다.)
3. 앱 Share 설정이 **공개(public)** 인지 확인합니다(패드에서 로그인 없이 열리도록).

## 행사장 준비

- 노트북: **Windows 키 + P → 확장**. 크롬 창 하나에 스크린 주소를 열어 프로젝터 쪽으로 끌어 놓고 **F11**, 화면을 한 번 클릭(효과음 켜짐). 노트북 화면에는 진행석 주소.
  - 확장이 어려우면 진행석은 내무계 직원 휴대폰으로 열어도 됩니다.
- 갤럭시탭: 크롬으로 말 옮기기 주소를 열고 가로로 둡니다. 와이파이 연결 확인.
- 시작 전에 진행석에서 한두 번 눌러 보고 [새 게임]으로 초기화합니다.

## 이럴 땐

| 상황 | 해결 |
|---|---|
| 결과를 잘못 눌렀어요 / 말을 잘못 옮겼어요 | 진행석 **↶ 되돌리기** (한 단계씩) |
| 패드가 안 돼요 | 진행석 아래 **"패드가 안 될 때 — 여기서 말 옮기기"** |
| 스크린이 안 바뀌어요 | 스크린 창을 새로고침(F5) 후 한 번 클릭 |
| 팀 이름·현수막을 바꾸고 싶어요 | 진행석 **팀 이름 · 현수막 글씨** (판은 그대로) |
| 앱이 다시 켜져서 판이 처음으로 돌아갔어요 | 무료 서버가 재시작되면 판이 지워집니다. 게임 중에는 코드를 고치지 마세요 |

## 파일

- `yutcore.py` 규칙·진행 상태 저장(SQLite) · `app.py` 세 화면 · `board_engine.py` + `static/` 스크린 3D 말판(브라우저에서 그림)
